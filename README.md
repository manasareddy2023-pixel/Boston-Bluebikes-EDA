# Boston-Bluebikes-EDA
Exploratory Data Analysis of Boston Bluebikes usage, rider behavior, time patterns, and weather conditions using Python.

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Boston Bluebikes data using Python.

The analysis focuses on understanding bike-sharing usage patterns, rider behavior, time-based trends, and the relationship between weather conditions and bike usage.

## Objectives

- Analyze bike-sharing usage patterns
- Understand rider behavior
- Identify time-based usage trends
- Analyze the effect of weather conditions
- Study relationships between different variables
- Identify important patterns and insights from the dataset

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data Understanding
- Data Cleaning
- Descriptive Statistics
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Correlation Analysis
- Data Visualization

## Dataset

The dataset contains information related to Boston Bluebikes usage, including rider information, time-related variables, and weather conditions.

## Project Files

- `Boston_Bluebikes_EDA.ipynb` - Complete EDA analysis
- `bluebike_data (1).csv` - Dataset used for the analysis

## Key Insights

The analysis explores patterns in bike usage across different time periods, rider types, and weather conditions and identifies relationships between important variables.

## How to Use

1. Download or clone this repository.
2. Open `Boston_Bluebikes_EDA.ipynb` in Jupyter Notebook or JupyterLab.
3. Make sure the dataset file is available in the same directory.
4. Run the notebook cells to reproduce the analysis.
